How it works. A GitHub Actions job runs every morning:

  1. Extract new calls from the City of Seattle open-data API.
  2. Load them into DuckDB, keyed on incident number, so re-running is safe.
  3. Transform with SQL into a clean staging view and summary tables.
  4. Check freshness, duplicates, missing values, missing days, coordinates and volume.
  5. Publish this page to GitHub Pages, only if every error-level check passed.

Machine-readable outputs: latest.json · daily_calls.csv · runs.json. Data: City of Seattle, public domain. Categories are assigned by keyword rules in 10_staging.sql.
